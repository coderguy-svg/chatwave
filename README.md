# ChatWave

A simple real-time chat app using GitHub Pages and Supabase.

## Setup

1. Create a Supabase project.
2. Open SQL Editor and run `schema.sql`.
3. Open `app.js`.
4. Replace:
   - `YOUR_SUPABASE_URL`
   - `YOUR_SUPABASE_ANON_KEY`
5. Upload `index.html`, `style.css`, and `app.js` to a GitHub repository.
6. Enable GitHub Pages in repository Settings → Pages.
7. Open the published site.

## Notes

- This starter includes email/password authentication and one-to-one text messaging.
- Supabase handles authentication, storage, database security, and realtime updates.
- For production, add stronger profile editing, moderation, file validation, rate limiting, and additional RLS policies.
